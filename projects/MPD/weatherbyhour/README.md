WEATHER BY HOUR

Weather by Hour is a weather dashboard that lets users search for a city and view its current weather, forecast information, and local time in one place.

I built this project to practice working with APIs, handling user input, and creating a more interactive web interface with JavaScript. I also wanted to focus on the smaller details that make a site feel smooth, such as search suggestions, validation, loading states, and animations.

FEATURES - 
- Search for cities and view current weather conditions
- City suggestions while typing
- Automatically selects the first matching city when searching
- Displays temperature, feels-like temperature, humidity, wind speed, and daily high/low temperatures
- Displays the local time for the selected location
- Updates weather information based on the selected city
- Handles empty and invalid searches
- Dropdown closes when clicking outside of the search area
- Weather information animates into view when new data loads
- Responsive layout

TECHNOLOGIES - 
- HTML
- CSS
- JavaScript
- Open-Meteo API
- Geocoding API
